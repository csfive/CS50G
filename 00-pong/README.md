# Pong

> Project 0 · [Official spec](https://cs50.harvard.edu/games/projects/0/pong/) · [Distribution code](https://cdn.cs50.net/2d/2025/x/projects/0/pong.zip)

## Objectives

- Implement a basic AI for either Player 1 or 2 (or both!).

## Specification

- Implement an AI-controlled paddle (either the left or the right will do) such that it will try to deflect the ball at all times. Since the paddle can move on only one axis (the Y axis), you will need to determine how to keep the paddle moving in relation to the ball. Currently, each paddle has its own chunk of code where input is detected by the keyboard; **this feels like an excellent place to put the code we need**! Once either the left or right paddle (or both, if desired) try to deflect the paddle on their own, you've done it!
- Be sure to comment your code in the place(s) where you implement the AI functionality. This is true for all implementations, but **particularly** if you do so in a spot we aren't expecting you to.

## Submission

- The contents of your branch must match the file structure of the unzipped distribution code exactly as originally received. Files should not be nested inside directories of your own creation or otherwise deviate from the provided structure.
- Record a screencast, not exceeding 5 minutes, demonstrating the game live and the AI functionality. Do not walk through code. It must not be a YouTube "short"; it must begin with a slide or text overlay containing both your edX and GitHub usernames; its description must be timestamped at the first point where the AI is demonstrated; and it must be uploaded less than one month before submitting the project form.
